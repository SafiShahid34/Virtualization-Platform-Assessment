# Virtualization Platform: Five-Year Cost and Risk Review

**[View the live report →](https://virtualization-platform-assessment.netlify.app)**

An anonymized portfolio case study on choosing where an organization's virtual desktops and servers should run after VMware's licensing changes.

## Overview

When Broadcom moved VMware to per-core subscriptions, many organizations had to decide whether to renew or move to another platform. This case study works through that decision for an on-premises environment that delivers virtual desktops to thin clients and remote users, alongside a set of server workloads.

## Viewing the report

The report is a single self-contained HTML file (`virtualization-platform-case-study.html`) with no build step. Open it in any browser, or use the hosted link above.
